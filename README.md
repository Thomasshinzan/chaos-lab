# CHAOS LAB (カオスゲーム・フラクタル実験アプリ)

**CHAOS LAB** は、カオスゲームおよび反復関数系 (IFS: Iterated Function System) に基づいて、ユーザーが数学的な移動ルールを自由に設定・編集し、その反復によって生成される複雑なフラクタル図形や幾何学模様を観察・実験できる汎用WEBアプリケーションです。

---

## 🌟 特徴と機能

### 1. 動作環境 & 技術構成
- **HTML5 / CSS3 / JavaScript (ES Modules)**
- **Canvas 2D API**: 2層キャンバス（累積点描画レイヤー + UI/ターゲットオーバーレイレイヤー）
- **Web Worker**: 計算ループをUIスレッドから分離し、100,000〜1,000,000点以上の大量プロットでも60fpsの滑らかな操作性を実現（Web Workerが利用できない環境では自動的にメインスレッドフォールバックで動作）。
- **外部ライブラリ非依存 (Vanilla JS)**: サーバーサイド処理不要。GitHub Pages等の静的ホスティングでそのまま動作。
- **完全レスポンシブ**: PCブラウザからスマートフォン（iPhone / Android）、iPad・タブレットまで対応。

### 2. 2つの実験モード
- **基本モード (カオスゲーム)**
  - ターゲット頂点（正多角形自動生成または画面タップによる任意追加・ドラッグ移動）を設定。
  - 多彩な移動方式：
    1. ターゲットへ接近 ($x' = x + r(tx - x), y' = y + r(ty - y)$)
    2. 中心へ接近
    3. 平行移動 ($dx, dy$)
    4. 回転移動 (指定中心周りの回転角 $\theta$)
    5. 拡大・縮小 (指定倍率 $s$)
    6. ランダム移動
- **上級モード (アフィン変換 / IFS)**
  - アフィン変換行列の直接指定 ($x' = ax + by + e, \ y' = cx + dy + f$)
  - 各ルールごとの選択確率と描画色設定
  - 異常値（NaN、無限大、極端な発散）に対する安全フェイルセーフ

### 3. ルール選択方式
- **均等ランダム (Uniform)**: 全ルールを等確率で選択
- **確率指定 (Weighted)**: ルールごとに確率（重み）を設定（自動正規化、全0時のエラーガード付き）
- **順番に実行 (Sequence)**: 登録ルールを巡回（Cyclic IFS）

### 4. 豊富な実験プリセット
1. **シェルピンスキーのギャスケット** (正三角形・50%接近・均等ランダム)
2. **四角形のカオスゲーム** (正方形・50%接近)
3. **五角形のカオスゲーム** (正五角形・黄金比接近)
4. **六角形のカオスゲーム** (正六角形・2/3接近)
5. **Barnsley Fern (バーンスレイのシダ)** (4つのアフィン変換と確率分布)
6. **Heighway Dragon (ドラゴン曲線)** (2つのアフィン変換)
7. **シェルピンスキーのカーペット** (8ターゲット・66.7%接近)

### 5. 直感的なビューポート操作
- **拡大・縮小**: マウスホイール、ピンチイン/アウト（タッチ操作）、ズームボタン
- **パン（移動）**: マウスドラッグ、1本指スワイプ
- **全体表示 (Fit View)**: 図形やターゲットのバウンディングボックスに自動ズーム・センタリング
- **ターゲットドラッグ**: 画面上のターゲットピンを直接ドラッグして座標をリアルタイム変更

### 6. 実験コントロール & 入出力
- **コントロール**: 開始 / 一時停止 / 再開 / 停止 / リセット / 1ステップ実行
- **リアルタイムHUD**: 現在ステップ数、総ステップ数、進捗率バー、処理速度 (pts/sec)、直前選択ルールランプ、現在座標 $P(n)$
- **設定の保存と読み込み**: 実験パラメータ一式をJSONファイルとしてエクスポート/インポート
- **高解像度PNG保存**: 生成した美しいフラクタル図形をワンクリックで画像保存

## 🚀 起動方法

### 静的ホスティング (GitHub Pagesなど)
リポジトリのルートに以下のファイルを配置するだけで動作します：
- `index.html`
- `style.css`
- `app.js`
- `simulation.js`
- `worker.js`

### ローカルでの動作確認
ES Modules および Web Worker を使用しているため、ローカルHTTPサーバー経由で開くことを推奨します（VS Codeの「Live Server」拡張機能や、Python / Node.js サーバー等）。

```bash
# Pythonを使用する場合
python -m http.server 8000

# Node.js (npx) を使用する場合
npx serve .
```
ブラウザで `http://localhost:8000` を開きます。
